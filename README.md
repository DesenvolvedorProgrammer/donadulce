# Hamburgueria Dona Dulce — prévia de site

Prévia de site desenvolvida pela **NH Digital** para a Hamburgueria Dona Dulce (Classic Burger, Poços de Caldas — MG).

Site estático (HTML, CSS e JavaScript), sem dependências e sem build. Para ver, abra o `index.html`.

- `index.html`: estrutura e conteúdo
- `style.css`: visual
- `cardapio.js`: cardápio completo (itens e preços)
- `script.js`: interações (WhatsApp, menu, abas do cardápio, revelações ao rolar, galeria, horário)
- `img/` e `fonts/`: fotos, logo e fontes

Na Vercel: importar o repositório, Framework Preset "Other", sem comando de build.
